# 건강폰술 — AI 개발 파이프라인

음주 대체 인터랙션 WebApp(건강폰술)을 **재사용 가능한 AI 개발 파이프라인**으로 구현하는 프로젝트입니다.
앱 자체의 완성보다, Claude Code를 중심에 둔 **AI 에이전트 파이프라인의 재사용성**이 본질입니다.

- **앱**: 건강폰술 — 실제 음주 없이 폰으로 술을 따르고 건배하는 절주·대체형 소셜 WebApp
- **플랫폼**: 앱인토스 (Toss 미니앱)
- **스택**: WebView (React 18 + Vite), 백엔드 없음(정적/CSR)

## CLAUDE.md 구조 — 루트가 진짜, `docs/`는 사람용

이 레포에는 같은 내용의 CLAUDE.md가 **두 형태**로 있습니다. 헷갈리지 않도록 명시합니다.

### 루트 = 실제 구동용 (Claude Code가 읽는 파일)

```
CLAUDE.md              # 진입점. @import로 아래 3개를 불러옴
├─ CLAUDE.pipeline.md  # ① 파이프라인 방법론 (앱·플랫폼 바뀌어도 유지)
├─ CLAUDE.platform.md  # ② 앱인토스 플랫폼 규칙 (플랫폼 바뀌면 교체)
└─ CLAUDE.context.md   # ③ 건강폰술 앱 컨텍스트 (아이디어 바뀌면 새로 씀)
```

- **이쪽이 실제로 동작하는 파일입니다.** Claude Code는 루트의 `CLAUDE.md`를 읽고, `@import`로 나머지 3개를 자동으로 불러옵니다.
- AI가 1차 독자이므로 **명령형으로 압축**했습니다. 준수율을 위해 "왜"는 인용구 한 줄로만 남겼습니다.

### `docs/` = 사람용 설계문서 (참고·검수·발표용)

```
docs/
├─ CLAUDE.design.md
├─ CLAUDE.pipeline.design.md
├─ CLAUDE.platform.design.md
└─ CLAUDE.context.design.md
```

- **이쪽은 Claude Code가 읽지 않습니다.** 결정 근거·맥락까지 담은 사람용 버전으로, 검수와 발표 자료로만 씁니다.
- 루트 구동용과 **같은 내용의 상세 레이어**입니다. 내용이 충돌하면 루트(구동용)가 기준입니다.

> 요약: **수정·실행은 루트 CLAUDE.md 쪽. `docs/`는 읽기용 설계 근거.**

## 파이프라인 단계

```
S1 기획·스펙 해석 → S2 구현 → S3 테스트 → S4 검수 → S5 배포
```

각 단계 사이에 **사람 검수 게이트**가 있습니다. 통과하지 못하면 다음 단계로 가지 않습니다.
자세한 단계 정의·수용 기준은 `CLAUDE.pipeline.md` 참조.

## 커밋 컨벤션

AI가 생성한 작업과 사람이 검수한 작업을 **커밋 단위에서 구분**합니다. (출처: `CLAUDE.pipeline.md` §6)

### 접두사

| 접두사 | 의미 | 예시 |
|---|---|---|
| `ai:` | AI(Claude Code)가 생성 — **사람 검수 전** | `ai: 따르기 인터랙션 구현` |
| `review:` | 사람이 검수·수정함 — 검수 통과 또는 수정 반영 | `review: 따르기 임계값 8%→10% 조정` |
| `docs:` | 문서(설계문서·README 등) 추가·수정 | `docs: ③ 샴페인 흔들기 반영` |
| `chore:` | 설정·빌드·의존성 등 잡무 | `chore: vite 설정 추가` |

### 규칙

- **`ai:` 커밋만 있는 변경은 머지·배포하지 않는다.** 반드시 `review:`로 사람 검수를 거친다.
- 형식: `<접두사> <한 일 요약>` (한글 OK)
- 한 커밋 = 하나의 논리적 변경. 여러 기능을 한 커밋에 몰지 않는다.

### 검수 마커

생성물 안에서 사람이 확인해야 할 지점은 코드·문서에 마커로 표시합니다. (출처: `CLAUDE.pipeline.md` §4.1)

| 마커 | 언제 |
|---|---|
| `// UNVERIFIED:` | 공식 문서로 검증 못 한 외부 동작 (SDK·정책·라이브러리) |
| `// ASSUMPTION:` | 문서에 없어 임의로 정한 값·동작 |
| `// REVIEW(사유):` | 되돌리기 어렵거나 사용자에게 노출되는 것 |
