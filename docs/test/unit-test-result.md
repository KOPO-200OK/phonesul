## 4. 발견 결함 및 관찰

### D-UT-01 — 손을 뗄 때 8% 기준 상태 분기가 화면에 연결되지 않음

| 항목 | 내용 |
|---|---|
| 심각도 | Major |
| 관련 요구사항 | F-CR-02, F-CR-04 |
| 근거 | `isHollow`는 단위 테스트만 존재하고 `PourInteraction.jsx`에서 호출되지 않음 |
| 실제 동작 | 100%가 되어야 `drink` 단계로 전환하며, 8~99%에서 손을 떼면 따르기 화면에 머묾 |
| 기대 동작 | 손을 뗀 수위가 8% 미만이면 대기, 8% 이상이면 마시기 단계로 전환 |
| 상태 | ACCEPTED · 현재 100% 충전 후 전환 UX를 제출 버전 동작으로 승인, 차기 스펙 정합화 대상 |

### O-UT-01 — 테스트 실행 경고

- React Router v7 future flag 경고 2종이 stderr에 출력됐다.
- 현재 테스트 실패나 기능 오류는 아니므로 Trivial로 분류한다.

## 5. 미검증·추가 필요 항목

- `audioPolicy.js`, `feedback.js`, `share.js`, `platform.js` 전용 단위 테스트가 없다.
- 단위 범위에서는 앱인토스 Storage SDK 대신 localStorage 폴백을 검증했다. 대상 환경 확인 결과는 통합 테스트 결과서에서 해소했다.
- 단위 범위에서는 fetch/WebSocket mock을 검증했다. 실제 네트워크·서버 결과는 통합 테스트 결과서에서 해소했다.
- 재연결 최대 횟수 소진, 비 JSON 메시지, 닫힌 소켓 송신 등 방어 경로의 일부 기대값이 없다.
- 임계값 8%, 탭당 25%, 재연결 간격은 제품 임의값이다. `// ASSUMPTION:`
