화면별 설계

04

공통 UI 규칙

모든 화면에 일관 적용되는 규칙이다. 검수 통과와 사용성 일관성을 위한 기준선이다.

항목규칙관련 기능
헤더좌측 뒤로/홈, 가운데 화면명, 우측 상단 닫기(X) 상시 노출F-SY-06
종료 처리닫기/뒤로로 앱을 벗어날 때 종료 확인 모달(S-10)을 거친다F-SY-05
상태 전환S-04는 한 화면 내 상태 전환. 요소 등장/퇴장으로 처리하고 라우트는 하나로 유지F-CR-02·03·04
피드백 원칙모든 동작은 시각 + 청각 + 촉각 중 둘 이상으로 전달. 진동/사운드를 꺼도 동작 인지 가능F-SY-01·02
사운드 정책무음 모드 시 자동 억제, 백그라운드 전환 시 즉시 정지·복귀 시 재생(시스템 자동)F-SY-03·04
성능첫 화면 10초 이내, 인터랙션 반응 2초 이내. 에셋 사전 로드F-SY-07·08
표현 가이드음주 미화·폭음 조장 금지, 술 브랜드 실명·로고 미사용. 샴페인 축하도 폭발 미화로 읽히지 않게F-CR-01·05
비게임 유지점수·레벨·랭킹·엔딩 없음. 핵심 루프는 대기↔따르기↔마시기 무한 반복F-CR-04 / F-HL-01
본 화면설계서는 기능정의서 v0.1과 1:1로 매핑된다. 검수 게이트에서 기능 ID 기준 교차 점검할 것. 색·연출·아이콘은 방향성 표현이며 비주얼 디자인 단계에서 확정한다.
