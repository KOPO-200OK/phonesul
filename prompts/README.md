# /prompts — 단계별 프롬프트 보관 (pipeline §6.1)

파이프라인 각 단계에서 Claude Code에 준 프롬프트를 여기에 저장하고 Git으로 버전 관리한다.

## 규칙
- 단계별 프롬프트를 파일로 남긴다 (예: `S1-spec.md`, `S2-skeleton.md`, …).
- 커밋 접두사: `ai:`(AI 생성·검수 전) / `review:`(사람 검수·수정 후) / `docs:` / `chore:`.
- `ai:` 커밋만 있는 변경은 머지·배포 금지 (pipeline §6).

## 기록
| 단계 | 프롬프트 파일 | 상태 |
|---|---|---|
| STEP 1 부트·정합성 확인 | (대화 로그) | 완료 |
| STEP 2 프로젝트 골격 | `S2-skeleton.md` | 본 커밋 |
